# Établi — gestion de garage automobile

MVP réalisé en Scrum (sprints de 2 semaines, du 26 octobre au 24 décembre 2026) par une squad de 5 personnes.

Stack : Docker · PostgreSQL · FastAPI · Next.js.

La documentation complète (démarrage, comptes de démo, architecture, tests) est complétée au fil des sprints.
